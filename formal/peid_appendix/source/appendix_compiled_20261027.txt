S1 Effective information: definition and evaluation
Effective information quantifies how strongly a transition mechanism constrains future states under a specified maximum-
entropy intervention. This section gives the common definition and then specializes its evaluation to discrete and continuous
variables.

S2 Two-source PID properties
This section specifies the redundancy properties used for the two-source PEID–PID correspondence. We state the axioms and
their consistency construction for finite-alphabet variables. For two sources X1 , X2 and a target Y , write

      I(X1 , X2 ;Y ) = Red(X1 , X2 ;Y ) +Un(X1 ;Y | X2 ) +Un(X2 ;Y | X1 ) + Syn(X1 , X2 ;Y ).                               (S19)

The single-source identities determine the unique contributions:

      Un(X1 ;Y | X2 ) = I(X1 ;Y ) − Red(X1 , X2 ;Y ),                                                                       (S20)

with the analogous expression for Un(X2 ;Y | X1 ). We consider non-negative bivariate decompositions satisfying the following
properties. Symmetry, self-redundancy and source monotonicity follow the Williams–Beer framework4, 5 ; Identity and
probabilistic left monotonicity specify the class used here.

Non-negativity (N).      The redundancy, both unique contributions and the synergy in Eq. (S19) are non-negative. In particular,
Red(X1 , X2 ;Y ) ≥ 0.

Symmetry (S).      Interchanging the two sources leaves redundancy unchanged:

      Red(X1 , X2 ;Y ) = Red(X2 , X1 ;Y ).                                                                                  (S21)

Self-redundancy (I).      For a single source,

      Red(X1 ;Y ) = I(X1 ;Y ).                                                                                              (S22)

Source monotonicity (M).         Adding a source cannot increase redundancy:

      Red(X1 , X2 ;Y ) ≤ min{I(X1 ;Y ), I(X2 ;Y )}.                                                                         (S23)

If X1 is a deterministic function of X2 , equality holds with I(X1 ;Y ); the corresponding statement holds after interchanging the
sources. This includes the usual source-inclusion equality.

Identity (Id).   For a target that copies the joint source, we adopt the Identity property of Harder et al.6 :

      Red(X1 , X2 ; (X1 , X2 )) = I(X1 ; X2 ).                                                                              (S24)


                                                                                                                             5/33
Probabilistic left monotonicity (PLM).  Processing the target through a stochastic channel cannot increase redundancy. For a
Markov chain (X1 , X2 ) → T → Z, equivalently Z ⊥ (X1 , X2 ) | T , we require

      Red(X1 , X2 ; Z) ≤ Red(X1 , X2 ; T ).                                                                                        (S25)

This is the probabilistic left monotonicity introduced by Rauh et al. (Section III, following Eq. (7))7 . It extends deterministic left
monotonicity5 to stochastic target channels, as needed for noisy transition models. We adopt PLM as an additional redundancy
property; no target chain rule for redundancy is assumed.

Consistency of the bivariate assumptions.                An explicit witness shows that these properties are compatible. Define

      R∗ (X1 , X2 ;Y ) = min{I(X1 ; X2 ), I(X1 ;Y ), I(X2 ;Y )},       R∗ (X1 ;Y ) = I(X1 ;Y ).                                    (S26)

Symmetry, self-redundancy and the monotonicity bound follow immediately. If X1 = f (X2 ), then I(X1 ; X2 ) = H(X1 ) and
I(X1 ;Y ) ≤ I(X2 ;Y ), giving the required equality. For the copied target, I(Xi ;Y ) = H(Xi ) for i = 1, 2. The minimum is therefore
I(X1 ; X2 ), proving Identity.
Under (X1 , X2 ) → T → Z, the ordinary mutual-information data processing inequality gives I(Xi ; Z) ≤ I(Xi ; T ) for i = 1, 2,
while I(X1 ; X2 ) is unchanged. Hence R∗ satisfies PLM.
To check the induced PID components, put a = I(X1 ;Y ), b = I(X2 ;Y ), c = I(X1 , X2 ;Y ) and d = I(X1 ; X2 ). The unique terms
are non-negative because R∗ ≤ a, b. Moreover,

      a + b − c = d − I(X1 ; X2 | Y ) ≤ d,        a + b − c ≤ a, b,                                                                (S27)

where the last two inequalities use c ≥ a, b. Thus a + b − c ≤ min{d, a, b} = R∗ , and the induced synergy c − a − b + R∗ is
non-negative. This construction establishes consistency for two sources. It serves only as a witness: the independent-source
result below holds for every redundancy functional in the specified class, without selecting R∗ as an estimator.


S3 Proofs of the PEID properties

Section S2. We then prove non-negativity and the upper bound of integrated effective information for arbitrary non-empty
source sets, followed by hierarchical additivity. The latter two results follow directly from mutual-information identities and the
common factorized intervention. Unless stated otherwise, A, B ⊆ V are non-empty source and target index sets, and information
quantities are evaluated under the same intervention-induced distribution qℓ (xt , xt+ℓ ). Information differences are used where
the participating terms are finite. The zero-redundancy bound also applies beyond finite alphabets whenever a redundancy
functional satisfying N, Id and PLM is defined on the relevant variables and copied target.

S4 Synergy Partition Tree implementation and split optimization
SPT is a recursive sequence of finite bipartition problems; it uses neither gradient descent nor a continuous optimizer. The
horizon ℓ, target B, intervention distribution, and EI estimator are fixed before tree construction.

S4.1 Node optimization and exact search
                                                                                         ˙ R. Define
At a non-singleton node A, each candidate is an unordered, non-trivial bipartition A = L ∪

      SA (L, R) = Ξℓ (L → B) + Ξℓ (R → B),                                                                                  (S45)
      rA (L, R) = Ξℓ (A → B) − SA (L, R).                                                                                   (S46)

Standard SPT maximizes SA , equivalently minimizes the raw residual rA , which is stored without clipping as the node synergy.
Candidates are ranked deterministically by decreasing SA , increasing rA , and then lexicographically by their source-index tuples.
The latter fields settle only numerical or exact ties.
For m = |A| ≤ mexact , the optimizer enumerates all 2m−1 − 1 unordered bipartitions: the first source is fixed in one child, all
subsets of the other m − 1 sources are enumerated, and the full set is excluded. The selected split is therefore globally optimal
among admissible splits at that node. Recursive selection remains greedy over the space of complete binary trees.

S4.2 Spectral candidates for large source sets
For larger nodes, a pairwise-synergy affinity matrix is computed once per experimental condition and its principal submatrix is
reused:
                                                          −1/2       −1/2
      Wi j = Ξℓ ({i, j} → B),   Wii = 0,        LA = I − DA      WA DA      ,   DA = diag(WA 1).                            (S47)

The inverse square root is set to zero for isolated vertices. A symmetric eigh decomposition of the normalized Laplacian
is used. Sources are stably sorted by each of the first four non-constant eigenvectors (or all available ones if fewer exist),
yielding the Fiedler ordering and up to three additional low-frequency orderings. Eigenvector sign does not affect the unordered
candidate set because reversing an order exchanges every prefix with its complement.

Two further orderings are included. Average-linkage clustering is applied to di j = 1 −Wi j / max p,q Wpq , with zero diagonal and

This section collects the background, governing equations and mechanism-related comparisons for six nonlinear benchmarks
(Supplementary Fig. 1). The coupled standard map and the controlled Hénon-inspired response model are deliberate extensions
or modifications of their classical antecedents. The comparison methods are whole-minus-sum information (WMS), minimum-
mutual-information partial information decomposition (MMI-PID), synergistic–unique–redundant decomposition (SURD), and
Shapley additive explanations (SHAP) interaction attribution applied to an MLP (MLP+SHAP).

PEID followed the parameter-dependent trends in all six models. Synergy increased with rotor coupling in the standard
map, peaked with neural gain in the Wilson–Cowan model, and showed the expected onset and saturation in the Ikeda and
Nicholson–Bailey systems. The Kuramoto and controlled Hénon models were more discriminating because redundancy or
single-source information changed alongside the joint effect. In the Kuramoto model, increasing redundancy drove WMS
below zero even though the joint coupling persisted; PEID retained a positive joint contribution. In the controlled Hénon model,
the explicit joint term weakened as a separable channel strengthened. PEID declined accordingly, whereas MMI-PID moved in
the opposite direction.
Two further contrasts separated synergy attributable to the specified transition mechanism from other quantities. SURD reported
its largest value at the weakest standard-map coupling, whereas MLP+SHAP continued to increase with output scale after the
information-theoretic estimates had plateaued in the Ikeda system. WMS reflects the balance between synergy and redundancy,
MMI-PID depends on the adopted redundancy definition, SURD decomposes predictive influence and MLP+SHAP attributes
changes in model output. These response differences limit interpreting every score as the strength of an irreducible joint
mechanism.

S9 Supplementary results

S9.1 Forecast-scale reorganization in global sea-level pressure
SLP variability reflects interactions among multiple atmospheric modes, yet how their joint predictive contributions change
with forecast horizon remains unclear(Supplementary Section S10.1.1). To characterize this horizon dependence, we learned a
transition model from observed weekly SLP modes and applied PEID under factorized interventions to quantify two-source
synergistic contributions to each target mode. We represent each source-pair–target relation as a synergistic hyperedge, weighted
by its corresponding synergistic causality, and examine how the dominant source combinations, their target coverage, and
individual synergistic relations change across forecast horizons (Fig. 4a–g).
The leading synergistic relations reorganize markedly with forecast horizon (Fig. 4a–c). At H = 1, strong hyperedges span
diverse source combinations, with the strongest linking a Maritime Continent–Indo-Pacific warm-pool mode (No. 0) and an
Arctic-related mode (No. 3) to a western North Pacific target (No. 37). By H = 10, a Maritime Continent mode (No. 0) and an
equatorial-Pacific ENSO-related mode (No. 1) emerge repeatedly among the leading relations. This concentration becomes
more pronounced by H = 60, when the strongest hyperedges are dominated by this source pair and extend to widely separated
targets. The prominence of this tropical pairing is physically notable given the established coupling between Maritime Continent
and equatorial-Pacific variability through ENSO teleconnections31 . This progression reveals an increasing concentration of
synergistic predictability around a recurrent tropical source combination at longer forecast horizons.
To test whether the concentration seen among the strongest hyperedges reflects a broader pattern, we examined the synergistic
relations across different ranking thresholds (Fig. 4d,e). Among the top 200 hyperedges, the number of distinct source pairs
decreases from 173 at H = 1 to 44 at H = 60, while the share of positive synergy contributed by the No. 0–No. 1 pair increases
from 0.6% to 25.3%, confirming that synergistic predictability becomes concentrated around fewer source combinations at
longer horizons. This increasing source concentration is accompanied by a broader geographical reach (Fig. 4f): for the
No. 0–No. 1 pair, the maximum target span approaches 20,000 km by H = 15 and then stabilizes, whereas the number of
reached targets continues to increase from 3 at H = 5 to 27 at H = 60. The dominant pair therefore establishes a broad spatial
reach before progressively connecting to more targets within that range. At the level of individual hyperedges (Fig. 4g), however,
different relations follow distinct trajectories with forecast horizon: the No. 0 + No. 3 → No. 37 relation weakens from its
maximum at H = 1, whereas others peak at intermediate horizons, plateau, or continue to strengthen. The emerging large-scale
pattern therefore reflects a redistribution among individual synergistic relations rather than a uniform change in their strengths.
The predictive structure of SLP thus exhibits a scale-dependent synergistic organization, with increasingly concentrated tropical
source combinations supporting joint predictive contributions across geographically distant targets.

S9.2 Task engagement reconfigures whole-brain synergy
We applied PEID to resting-state and seven task fMRI conditions from the HCP S1200 release, with 1,015–1,054 eligible
participants per state (Supplementary Fig. 5a). Mean system-level Ξ was 4.95 nats in REST and 3.24–4.25 nats across tasks.
Comparisons used the participants available in both REST and each task, and all seven paired contrasts survived false-discovery-
rate correction. These full-run differences depend partly on sequence length: after matching REST duration to each task, the
REST advantage persisted for six tasks but reversed for SOCIAL (Supplementary Section S10.2.2).
Across all eight states, the mean SPT contribution was largest at nodes containing six source networks (Supplementary Fig. 5b),
while the seven-network root contribution was larger in REST than in any task in the full-run analysis. Functional-network
attribution also changed with state (Supplementary Fig. 5c). The Limbic network received the smallest mean share throughout,
whereas the Control share increased from 12.50% in REST to 14.54–17.92% across tasks and peaked during LANGUAGE.
Thus, state differences involved both the overall information budget and its distribution across network combinations and


                                                                                                                              18/33
functional subsystems.
The broader distribution of Ξ across participants during REST may partly reflect heterogeneity in ongoing cognition without a
shared task. Individuals differ in the content and form of spontaneous thought, including memories, future-oriented thinking,
inner speech and imagery. Experience-sampling and neuroimaging studies document this diversity and associate characteristics
of self-generated thought with intrinsic brain activity32, 33 . Shared task demands may constrain this source of heterogeneity by
directing attention toward common stimuli and goals, offering one possible explanation for the narrower distributions observed
here. Variation in vigilance may also contribute34 . These explanations remain provisional because thought content and vigilance

S10.1.2 Pretrained UniCM transition model
UniCM is a dual-view spatiotemporal Transformer for joint prediction of global climate modes and gridded ocean–atmosphere
fields38 . Its Globalformer branch evolves five physical fields, whereas its Modeformer branch evolves a compact set of
climate-mode indices. Mode-to-patch guidance transfers the Modeformer representation to the spatial tokens of Globalformer,
thereby coupling the two predictive views. Both branches use encoder–decoder Transformers with separated temporal and
spatial (or mode-wise) attention.
The original model was trained on 165 years of curated CMIP6 simulations comprising four runs from CESM2 and EC-Earth3.
Samples were formed with a 12-month history, a 24-month forecast target, and a one-month sliding stride. Training used
AdamW with an initial learning rate of 5 × 10−4 , weight decay 10−6 , batch size 32, gradient-norm clipping at 1.0, and dropout
0.2. A three-epoch linear warm-up was followed by cosine learning-rate decay; training continued for 200 epochs and the
checkpoint with the lowest validation loss was retained38 . We used the released pretrained weights and did not repeat this
optimization or fine-tune the model.
The checkpoint-compatible implementation analyzed here uses five physical channels: sea-surface temperature, zonal and
meridional surface wind stress, upper-ocean heat content over 0–300 m, and the depth of the 20 ◦ C isotherm. The fields are
represented on a 5◦ × 5◦ grid of 12 × 72 cells and partitioned into 2 × 2 patches, yielding 216 physical tokens per month.
Whereas the published formulation reports seven primary climate modes, the released checkpoint variant used here exposes 11
Modeformer channels: ENSO, NPMM, SPMM, IOB, IOD, SIOD, TNA, Niño 1+2, Niño 3, Niño 4, and a warm-water-volume
proxy derived from the 20 ◦ C isotherm depth. This distinction is recorded explicitly because the PEID intervention dimension
is determined by the checkpoint interface rather than by the shorter list in the model overview.
For PEID, each checkpoint was loaded strictly, placed in evaluation mode, and kept frozen. We queried only the Modeformer
transition from the full 12-month, 11-mode history to the 24-month autoregressive forecast. The same maximum-entropy
intervention ensemble was used for all three checkpoints, so between-seed variation reflects pretrained-model variability rather
than different intervention samples. Actual ORAS5 fit-period trajectories supplied the observational comparison priors and
calibration data; later observations supplied validation and testing.
For forecast calibration, monthly ORAS5 trajectories spanning 1980–2018 were transformed into 12-month histories and 24-
month prediction targets through the 11-mode checkpoint interface. To prevent temporal leakage, calendar-month climatologies
and field-wide anomaly scales were fitted only on raw months from January 1980 through December 2003, which cover the
253 calibration-fit issue dates through December 2001 and all of their 24-month targets, and were then frozen for all later
months. Hyperparameters were selected on 36 issue dates from January 2004 through December 2006, and the untouched test
set contained 96 issue dates from January 2009 through December 2016, with targets extending through December 2018. The
intervening 24-month gaps prevent target-month overlap across fit, validation, and test partitions; neither validation nor test

S10.2.2 HCP Schaefer-1000 functional data and state comparisons

Participants and cortical representation.        We used all eligible standard-length LR runs from the HCP S1200 release,
comprising 1,071 participants with at least one eligible state. State-wise sample sizes were 1,054 for REST, 1,017 for
EMOTION, 1,053 for GAMBLING, 1,023 for LANGUAGE, 1,049 for MOTOR, 1,015 for RELATIONAL, 1,025 for SOCIAL
and 1,054 for WM. A missing or ineligible run excluded only that participant–state combination. REST–task comparisons used
the paired intersection for each task, with 1,001–1,038 participants. All series used the Schaefer-1000 parcellation and seven
Yeo networks, without global signal regression. Within each network, one principal component was fitted on the first 75% of
the run. For tasks, PCA used the task-related component reconstructed from the temporal design by ordinary least squares, and
its loadings were applied to the retained signal; REST PCA used the resting-state signal directly. This yielded seven network
scores per time point.

Transition model and information queries.       Each participant–state series was fitted independently with a third-order linear
∆-Ridge model (α = 1), using the first 75% of samples. The remaining samples provided prediction diagnostics. The source
contained three lags of each network score (21 scalar coordinates), and every source subset retained the same seven-dimensional
next-state target. Interventions were independent standard Gaussian inputs in the standardized source coordinates. All EI
queries used analytic log-determinant calculations from one affine-Gaussian transport-map channel, marginalizing omitted
sources under that intervention. Because the task-design reconstruction and original temporal preprocessing used the complete
run, the final segment is a dynamics diagnostic rather than a fully independent prospective test.

SPT contributions and network attribution.      The three lags of each network formed one source block. SPT construction
exhaustively evaluated candidate binary splits and continued to singleton networks. For Supplementary Fig. 5b, local split
contributions were summed by the number of networks in their parent node, then averaged across participants. Their sum
is the between-network component; within-network contributions remain in the leaf blocks. For panel c, each network’s
within-network Ξ was added to its exact Shapley allocation of the between-network residual, evaluated over all 27 = 128
network subsets. These seven contributions sum to system-level Ξ. Each participant’s allocations were normalized by that
participant’s own Ξ before averaging.

Paired comparisons and sequence-length sensitivity. REST was contrasted with each task using two-sided paired
Wilcoxon tests, followed by Benjamini–Hochberg correction across the seven contrasts at a false-discovery rate of 0.0542 . The
participant was the pairing unit. For the duration control, each REST run supplied 12 evenly spaced windows matching that
participant’s task length. PCA and dynamics were refitted within each window, and the 12 estimates were averaged before
participant-level comparison. The REST advantage remained significant for six tasks but reversed for SOCIAL. Control-network
share increases persisted across all seven tasks in this duration control.

S10.3 Urban mobility data and preprocessing
Trip records and spatial aggregation. We used the publicly downloadable 2023 New York City Taxi and Limousine
Commission Yellow Taxi Trip Records. Starting from 38,310,226 raw trips, we retained trips whose pickup and drop-off


                                                                                                                          25/33
locations were both among 66 active Manhattan taxi zones and differed from one another. The three inactive Manhattan zone
identifiers 103–105 were excluded. Trips were aggregated into 8,760 consecutive hourly observations. For each zone and hour,
inflow was defined as the number of retained trips ending in that zone at the drop-off hour, and outflow as the number beginning
in that zone at the pickup hour.

Temporal split and model inputs.          Samples were divided chronologically into 70% training, 20% validation, and 10%
test sets; all standardization statistics were estimated from training target times only. We reproduced the multi-granularity
spatio-temporal network (MGSTN)43 , which predicts next-hour inflow and outflow for all 66 zones from three non-overlapping
temporal branches. The recent branch used the preceding 7 consecutive hours, the daily branch used the same hour from the
preceding 5 days, and the weekly branch used the same hour from the preceding 7 weeks. Calendar and weather attributes
were supplied to the corresponding temporal inputs. Three independently trained model checkpoints were frozen before the
information analysis.

Representative traffic states.   State-conditioned analyses used three representative timestamps selected within the validation
period. Weekday peak was the highest-total-flow observation among weekdays at 08:00–09:00, weekend midday was the
highest-total-flow observation among weekends at 12:00–14:00, and rainy high demand was the highest-total-flow observation
among hours with positive precipitation. These timestamps define controlled model states for comparing the estimated
information quantities.

Temporal source groups and regional synergy.              For zone i, the recent, daily and weekly histories were denoted by ri ,
d i and wi , respectively, and yi was the next-hour inflow–outflow target. The regional analysis compared recent history with

Finite-amplitude interventions and estimation.         The two source blocks in each regional comparison were independently
bootstrapped from training-period empirical windows. Within the periodic block, daily and weekly histories came from the
same sampled window, preserving their empirical dependence. For temporal interventions, the other zones remained at the

magnitudes, then reduced to two principal components per block. PCA and second-order autoregressive triangular transport
maps were fitted on 70% of the intervention samples; conditional mutual information was evaluated on the remaining 30%.

Citywide temporal hierarchy.     The SPT analysis retained recent, daily and weekly histories separately for every zone, giving
66 × 3 = 198 source blocks. Each block was bootstrapped independently from training-period windows and represented by
two standardized principal components of the same indicator–magnitude encoding. All blocks shared 4,096 interventions,
with preprocessing and density estimation fitted on the same 70% subset. The target was the joint 132-dimensional next-hour
inflow–outflow vector for all zones, with validation-residual noise added. To evaluate the many high-dimensional subset queries,
EI values were computed from a common affine/Gaussian channel fitted to these source components and target responses. The
unconstrained SPT selected splits by maximizing the sum of child Ξ, searching all binary splits for nodes of at most eight
source blocks and spectral candidates for larger nodes, and continued to singleton blocks. A separate time-block-constrained
analysis compared all three ways to isolate one complete temporal scale at the root, then split the remaining pair into its two
scales before searching within-scale spatial structure. Neither tree premerged daily and weekly histories.
