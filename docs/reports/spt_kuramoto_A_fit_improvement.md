## 数据与公平性

- 固定原 Kuramoto A 网络、权重、频率和噪声0.08；与先前保存的 `frozen_model.json` 中 network 逐项相等。
- 16,384条独立轨迹，初始九维相位独立均匀分布于 `[-π,π)`，随后自由演化，不在轨迹中替换节点状态。保留前4个 `τ=0.2` 转移，积分步长 `dt=0.0025`，共65,536对。
- 这批数据是用户允许的**受控多初值自由演化及其过渡段**，不是烧入后稳态采样。第一步的源分布恰好覆盖后续干预域，须如实声明采样设计。
- 按整条轨迹固定划分12,288/2,048/2,048条训练/验证/测试，即49,152/8,192/8,192对；轨迹间不交叉，每份数据保留相同年龄层。所有输入、输出标准化只拟合训练集。
- 两个新模型的训练数组摘要完全相同，验证和测试数组摘要也相同。唯一主数据池、轨迹编号和时间索引已保存，供SPT、SHAP、WMS、SURD后续共用。SPT和SHAP应共享最终同一冻结MLP；本轮未重算WMS/SURD，旧基线分数不能与新数据模型直接组成公平排名。
- 真实方程仅用于生成自然观测和冻结后的验收。拟合器不接收真实支持、模块标签、真实系数、解析均值或梯度；未按F1选择任何参数。

## 冻结后的验收

条件均值由128个独立探针、每点256次真实随机转移的圆周均值估计。误差按圆周差计算；相对分母为真实平均相位增量相对“保持当前状态”的RMS，而非受恒等跳连主导的完整未来状态大小。下表使用另一随机种子的最终独立均匀探针，和工程诊断分开。

| 指标 | 历史稳态 MLP | 新自然数据原 MLP | 新自然数据周期 MLP |
|---|---:|---:|---:|
| 独立均匀域条件均值RMSE，rad | 0.149096 | 0.019437 | **0.011979** |
| 同上相对误差 | 98.43% | 12.83% | **7.91%** |
| 增量Jacobian相对Frobenius误差 | 99.73% | 24.06% | **11.81%** |
| 两源混合响应相对Frobenius误差 | 99.86% | 44.07% | **24.55%** |

均匀域真实平均增量RMS约0.151472 rad，MC均值参考噪声RMS约0.002242 rad，低于5%目标的一半；误差表保留原始MC参考误差，没有静默扣噪或截断。MC圆周均值仍不是精确解析真值，数值门槛不是恢复F1的充分条件。

Jacobian诊断用16个独立均匀状态，每点64次模拟，差分步长0.001 rad，正负扰动共用Brownian增量。比较的是完整未来Jacobian减去恒等矩阵，避免恒等跳连掩盖机制误差。联合诊断用8个状态、所有36输入对、每点16次模拟、四角共同噪声，步长0.05 rad；不按真实边筛选。两者都是有限MC差分参考，未对其精度做完整收敛证明，接近门槛的差异尤其不宜过度解释。

另外生成了完全独立于主数据池和工程探针的最终自然轨迹队列（128个状态，每点256次模拟）。周期方案条件均值RMSE为0.011236 rad，相对误差8.33%；原MLP为0.017496 rad、12.97%。主结果缓存里的 `final/natural_test` 仍来自原留出测试池；这个补充队列才提供额外独立的自然轨迹验收。

## 带噪预测、滚动和条件分布

| 主数据池指标 | 原 MLP | 周期 MLP |
|---|---:|---:|
| 自然验证单次带噪未来RMSE，rad | 0.038740 | 0.036302 |
| 自然测试单次带噪未来RMSE，rad | 0.038731 | 0.036292 |
| 测试年龄0/1/2/3的RMSE，rad | 0.04085 / 0.03944 / 0.03792 / 0.03657 | 0.03793 / 0.03679 / 0.03549 / 0.03488 |
| 自然验证残差最大绝对非对角相关 | 0.0313 | 0.0691 |
| 留出完整协方差的局部Gaussian 95%联合覆盖 | 93.85% | 94.13% |

完整自然未来误差含不可约扩散噪声，不能把约0.036 rad当成全部机制拟合误差，也不能只凭该误差或约94%的总体覆盖宣布条件分布正确。留出验证残差的完整9×9协方差已保存且正定，无任意噪声下限。

独立均匀探针上的条件方差跨状态P90/P10比值约1.52–2.23，提示固定方差近似仍需检查；MC样本方差本身也有估计误差。本轮模型适配器仍是**独立、常集中度von Mises残差**，训练残差定标；保留完整协方差不等于已经实现或验证了完整相关条件TM。下一阶段必须核验状态依赖方差和相关性，不能把均值改善自动等同于EI可用的转移密度准确。

64个新初值、每点256条真实轨迹的4步检查中，反复应用周期MLP均值映射相对真实轨迹MC均值的RMSE依次为0.01212、0.02270、0.03188、0.04063 rad；原MLP为0.01899、0.03451、0.04719、0.05825 rad。第二步起，迭代均值映射一般不等于随机过程的预测均值，因此这是滚动诊断，不能全部解读为单步拟合偏差。

## 当前判断和后续边界

这轮同时扩充样本并改变自然数据的联合覆盖，已把相同原MLP的干预域均值误差大幅降低；周期方案继续改善。单独的数据量效应和多初值覆盖效应尚未分离，不能宣称仅增加稳态长度也会获得相同效果。

当前仍未通过拟合验收，尤其联合响应误差保留约四分之一；不据此计算或承诺高F1。下一轮优先用同一采样协议扩大共同独立轨迹池至262,144对，保持已登记周期方案作样本量对照，再视验证证据处理优化和条件噪声。这个更大训练、LV/B推广和SPT计算均未在本轮启动。
