# B：局部高阶 Kuramoto 的 SPT 与 ΦR 对比

2026-10-15。用户在上一轮 A/B/C 精度试验后，批准仅对 B 追加最多 4 小时计算，随后指定只比较 SPT 与 ΦR 相关方法。用户随后进一步移除所有 HAC 方法，本轮只保留三方法；既有 Pair Ξ / Future MI / Pair ΦR + HAC 缓存作为历史记录保留，不纳入当前图表与效果判断。复用已拟合模型，不按恢复分数调整动力学、噪声、数据种子或学习参数。[上一轮报告](spt_local_kuramoto_validation.md)及所有失败缓存保留。

## 执行前协议

- 问题：固定 B 动力学和共同学习联合，比较 SPT、Block ΦR、按较小子组节点数归一化的 Block ΦR。主指标为原有 support/clade F1，辅以根恢复、上层召回和数值稳定性。
- 控制：九节点单相位，原 B 超边；`K0=1, rho=.5, sigma=.08, tau=.2, dt=.0025`。共同源为九相位独立均匀干预，完整未来九相位作为 SPT 固定 target。其余方法保留各自定义的群组/成对未来 target，均为同一个冻结联合的边缘。
- 数据：复用 seed 0 的 16384/4096/4096 训练/验证/测试及冻结 learned-flow + product-von-Mises 条件 TM。所有方法共享该联合及实际外层样本；不把四个积分 scramble 或标签置换当成四个独立物理数据集。
- 完整源表：`N=1024, P=256`，4 个 scramble，复用原 35 项部分表及对应关键查询；先审计全部 9330 个 raw Syn 二分，并单独检查 integrated Ξ。原生非负容差仍为 `.01 nats`，保存 raw 值与容差内负数计数，显著违规明确失败，不裁剪。
- 群组查询：首先原试算 `N=256`，成本检查后采用 `N=128` 完整候选枚举，informed proposal 用 256 粒子，纯先验积分用 1024 粒子，4 个 scramble；informed 分支保存 64 粒子前缀，SMC 分支保存独立 256 粒子对照及较小外层前缀，缓存每个条件边缘，供后续加密复用。选中树及竞争切分按数值诊断追加精度检查；所有初始搜索枚举完整候选二分，未限制为真实支持。未充分分辨的树只报告探索性结果和稳定性。
- 使用既有共同评分函数。真实支持仅进入生成器、预设诊断位置和事后评分，不进入拟合器、群组密度估计或候选选择。
- 解释：先回答此单数据集上差距是否明显且数值稳定。没有独立物理数据重复时，不给总体显著性 p 值或将数值重复包装成统计样本。
- 预算：本轮单独保存开始时刻及硬截止，预留最终图文核查时间。运行健康检查每约 10 分钟读取原生日志与缓存；结束、失败或预算到期后删除检查任务。

## 手稿与估计对象

本轮重新通过 Zotero 按题名核验父项 `P6UJCVG8`：*Emergent hierarchical organization of causal interactions in complex systems*，重新获取唯一主文 `DXGC7JEA`（19 页）及 SI `MWIWKSVG`（28 页）全文，阅读 Methods 式（4）–（12）、SI S1.2 式（S7）–（S15）、S5.1 式（S49）–（S50）及 S7 式（S67）–（S71）。仍无明确稿件日期/版本；附件 10 月 4 日修改时间不能据以确定新版。与上一轮相同：固定共同干预、未来相位 target 和标准 raw-residual SPT；此九节点完整未来相位及周期条件 TM 不等同于手稿六节点增量 target 的具体实现。

群组 target 不能用 source-to-full-target 表替代。对任意源 A 和 target B，把缺失源分成 D=B\A 与 U=V\(A∪B)。U 从原均匀先验采样；给定 U、已知源和目标，为 D 构造规范化 proposal。U 的 prior/proposal 抵消后，权重使用完整的 `p(yB|x)`、D 的均匀先验及实际条件 proposal 密度。这只改变积分方法，没有重新拟合群组模型。

当 U 为空时沿用原 8 次 Gauss–Newton proposal；D 为空时仅作先验积分。两者均非空时，为控制逐粒子 Jacobian 成本，采用 4 次 Picard 均值校正及固定 `1.5/sqrt(kappa_D)` 对角尺度。三成分混合仍为 80% 局部、15% 两倍标准差、5% 均匀，使用真实混合密度计算权重。Picard center 无需等于后验 mode；其残差只作为效率诊断，不冒充 Newton 收敛或 EI 误差界。U、混合分支、D 采样使用互不重叠的 Sobol 坐标。只读数值审查确认该权重与共同联合一致；新增测试覆盖独立解析控制、缺失源不泄漏和独立数值积分对照。

执行前 smoke 检查发现，部分纯先验分子在 256 粒子时最低 ESS 低于 10，因此将该分支统一加密至 1024。Picard 校正的 residual 若超过目标噪声标准差的 `.25`，仅对对应 nuisance draw 用 4 次 GN 重新求解 proposal，并在采样及密度中使用实际替代中心和协方差。目标 31 的分母最低 ESS 在该修正后由 1.71 提高到 42.58；这是 proposal 诊断，不是恢复分数。本轮修改均在查看群组方法 F1 前固定。

ΦR 点估计先将每项 EI 的四个 scramble 平均，再取四项互信息的 MMI 最小值。逐 scramble 的 ΦR 单独用于数值误差与树稳定性。额外保存两种聚合的差，避免将 `mean(min EI)` 的有限精度向下偏差当成标准平均 EI oracle 的结果。raw 非负审计同时涵盖点估计与各次重复。

后续精度复核原先预设为 SPT 竞争候选；在去除 HAC 后，预算内并行尝试完整的 `N=4096, P=256`、511 源子集与 4 次重复，避免只检查旧树节点而遗漏新父节点。两项工作分别使用 4 个原生计算线程，本机有 10 个物理核心；仍服从同一硬截止。若完整高档表未完成，不能把部分表当完整树。群组方法只对相同规则筛选的 Block 候选使用 `N=256`、informed 512 粒子、纯先验 1024 粒子，full-target 项继续其已注册的 256 粒子流。8 SEM 加观测粒子加密变化筛选是预算内启发式，**不是同时置信界**；初始全枚举加高档竞争候选复核不能称为全部 9330 切分的高精度认证。程序 `complete` 只表示该阶段算完，数值门槛和排名稳定性另行报告。

## 第二版边缘积分修复

第一版纯先验积分仍出现最低 ESS≈1.2，raw ΦR 最小 −0.02505 nats（容差 −0.01），因此明确终止，旧值不用于评分，也不记为算法 0 分。旧缓存保留并标为数值失败。

第二版在 D 为空时，使用独立的 1024 粒子 pilot：若 ESS<64 或最大权重>.05，生产积分采用 1024 粒子 annealed SMC，否则使用独立 scrambled Sobol 先验积分。SMC 从归一化均匀先验开始，粗档 βk=(k/8)²、一次 MH move；复核档 βk=(k/16)²、两次 MH move。每层先累积增量 logmean 权重，再进行无偏 systematic 重采样及保持目标不变的 MH move；固定 10% 均匀跳跃混合和对称 wrapped Gaussian，步长由独立 pilot Fisher 确定为 .7/sqrt(.3+β Fisher)。末层完成证据累积后省略无关的 move。1024 与独立 256 粒子 SMC 对照是粒子数检查，不是严格前缀检查。SMC 无偏的是证据 Z，不能据此声称 logZ 无偏或已通过精度门槛。

粗档降低层数与 move 数是基于执行成本及已完成试算重采样前 ESS 最低仍约 760/1024 的效率诊断；在看到 Block 分数前固定。相同目标的有效旧版 16 层/2 moves 原始边缘允许复用，并保留实际参数。首批 N=256 原始 log-density 的前 128 个共同外层样本可重用，标记来源；原诊断极值对该前缀是保守界，SMC 计数不冒充 N=128 的实际计数。复核候选筛选同时加入观测粒子加密变化的余量，仍非全局最优性认证。

SMC 保存每层重采样前 ESS、最大增量权重、初始祖先存活数和 local/uniform 接受率；这些 ESS 与普通 importance sampling 的最终权重 ESS 含义不同。四次重复包含 RQMC 和普通 SMC 随机性，统一称数值重复。其余 informed 分支改用 Picard center 处实际 Jacobian 的局部协方差，保留规范化混合权重。旧版仅诊断合格的非 D0 原始边缘可复用，并记录来源；所有旧 D0 和 EI/ΦR 组合均重新计算。修复的核心权重、种子独立性与缺失源不泄漏已由只读代理审计，新增测试用常数似然和尖锐周期似然的独立求积控制核对 SMC 证据。

手稿 SI 气候应用 p22 的 ΦR 使用观测联合；此处共享独立均匀干预联合，且递归 Block 和 min-child-node 归一化属于项目适配。四互信息 MMI 公式一致，但不能声称复现了该气候应用的具体算法。
