# 搜索非线性依赖聚类的困难动力系统

2026-10-16。目标是找到成对依赖构树恢复较差、而同数据拟合MLP后的SPT具有较大F1优势的系统。本轮已完成文献检索和既有缓存的轻量复核；尚未启动新增动力学扫描、MLP训练或EI积分，也未延长任何旧预算。

## HO-LV的0.833具体错在哪里

原9节点HO-LV A的Song AUV2平均连接树先正确形成{1,2,3,4,5}、{6,7}、{8,9}，之后把{6,7}并入{1,2,3,4,5}，产生错误的七节点clade，漏掉参考{6,7,8,9}。

| 候选合并 | 平均AUV2相似度（无量纲） |
|---|---:|
| 实际选中的{1,2,3,4,5}与{6,7} | 0.02486155 |
| 参考结构需要的{6,7}与{8,9} | 0.02440190 |
| 前者减后者 | 0.00045965 |

这定位了平均连接的错误决策，尚未确定其物理原因。该方法四个12链子集的模块F1从0.462到1，旧KSG适配在完整池又得到1。因此，当前0.833可能混合了有限样本MI偏差、熵归一化与平均连接的影响，不能仅凭这个小差值宣称动力学存在稳定的不可恢复边界。

## 已找到的缓存候选

只读取已有两个固定λ=.05的有界Hénon式网络。SPT原生缓存确实来自同一自然训练集拟合的6–64–64–6 SiLU MLP，之后才使用独立均匀干预和条件残差TM；本次逐项核对训练数组、MLP参数和原生树的摘要。没有重拟合、重算EI或改动旧结果。

这里沿用原实验在拟合前定义的**根切K=2、同模块节点对F1**，不在树中搜索最佳切层。它与9节点实验的完整层次模块clade F1不同，不能直接将两张表混合排名。

| 系统 | 既有MLP-SPT均值树 | Ward | Average／UPGMA | Song AUV2＋average |
|---|---:|---:|---:|---:|
| Hénon式3+3，两组三源乘积 | 1.000 | 1.000 | 1.000 | 1.000 |
| Hénon式4+2，四源乘积和二源乘积 | **1.000†** | **1.000** | **1.000** | **0.429** |

4+2的参考模块为{1,2,3,4}与{5,6}，Song树根给出{1,3}与{2,4,5,6}，精确模块集合F1为0；节点对F1差值为4/7≈0.571。四个训练链子集的Song节点对F1为0.615、0.471、0.471、0.706。

作为估计器诊断，用之前公开的KSG/copula/C−MI适配，在同一完整12288行训练池、k=5下重复计算成对依赖。4+2得到同样的错误根切，节点对F1仍为0.429；3+3为0.308。该适配不新增为正式已发表基线，也不是Song的另一种原文实现。4+2的15个原始KSG成对MI估计范围约为−0.00397至0.01207 nats。两个估计器均失败支持进一步研究成对信号弱的可能性，但不证明所有MI估计器或所有非线性聚类都会失败。

† **这个大差距目前只能算候选。** 4+2只有一个物理数据种子。既有SPT四次数值积分的诊断F1为1、1、0.471、1；均值树最优与次优根切的差仅0.00164 nats。四源模块的干预域均值误差／真实乘积信号RMS约1.45，尚不能认证该四源机制被准确学习。Ward和average也为1，不能写成SPT独占最优，更不能写成相对所有层次聚类的显著优势。

这是明确构造的有界随机Hénon-inspired网络，包含二次折叠、三／四源乘积、tanh和噪声，**不是经典Hénon映射的原样复现**。完整定义和旧结果见[原报告](henon_fixed_lambda_module_recovery.md)。

最后一类的均匀不变性不要求每条有限轨迹已经遍历全部环面；这里讨论的是均匀初始集合的分布。单轨迹、非均匀初始分布、不同采样条件、时间滞后和转移信息会改变结论。转子状态若为(q,p)二维块，双方都必须得到同一完整状态块；不能只给聚类q而让MLP额外获得p。此方向一旦执行，需明确新的源块和目标，与旧九标量案例分开报告。

## 待批准的首轮搜索协议

建议新增**最多60分钟共享墙钟预算**，不启动子代理，不重置旧8小时、旧15分钟或旧30分钟预算。更轻方案是只保留上述缓存诊断，不生成新数据；也可将新计算限制为30分钟，接受只完成少数候选。

第一轮固定8个机制／网络条件：现有Kuramoto与HO-LV两族×现有两种A/B拓扑×二体项相对增益{1,0.1}。三体项保持原幅值，二体项统一缩放；不修改聚类算法、MI估计器或连接规则。保留原动力学局部项、噪声和时间步长；若原LV的稳定化系数依赖耦合总量，需明确其随构造变化，不能强称单因素隔离。各条件的参考层次在生成数据前按实际权重构造并检查，不直接套用可能失效的旧真值。所有候选、失败和被排除原因保留。

数据优先采用共同的多初值自由演化集合：每条件16384条独立初始轨迹，各保留4个τ=.2转移，共65536对，按整轨迹48/8/8比例划分。Kuramoto初始相位和LV原生log丰度支持均预先固定为(−π,π)；不在轨迹中重置单节点。该集合含初始化与过渡段，不能称为烧入后的稳态样本。三个聚类方法和MLP共用同一池、同一训练行；静态构树只使用源状态、MLP学习转移，输入用途差异照实报告。

先对全部8条件执行固定的三个聚类方法和信号／状态覆盖诊断，再按公开的MI困难程度及可学习性条件保留最多2个候选进入MLP→条件TM→完整SPT。这是**寻找反例的探索性筛选**，不是随机抽取系统的总体平均性能评估。已有未通过干预域诊断的模型不能直接当作成功证据。

拟合方案预先固定：两层128单元SiLU残差MLP，标准化状态增量为回归目标，AdamW(lr=.003, weight_decay=1e-5)，batch=1024，最多800轮，最少200轮后才允许100轮无验证改善早停，seed=20261016；依共享截止提前终止时如实记录。Kuramoto使用sin/cos原始相位及所有节点对k=1/2相位差的sin/cos作为输入；LV使用原生u、exp(u/π)和所有无序节点对的丰度乘积。候选特征对所有节点统一枚举，不输入真实超边、系数或模块。只固定这一套已有拟合改进思路，不对多套容量、学习率和特征按F1择优；验证集仅用于轮次选择。它包含动力学家族先验，需明确比较对象是“状态表示＋MLP＋SPT”整条路线，不将全部增益归因于最后一步切树。

验收分开执行：先检查自然留出转移和独立诊断状态上的均值／联合响应，沿用既有工程目标（条件均值NRMSE≤5%、Jacobian相对误差≤10%，近零响应另报绝对误差）；再冻结MLP与显式条件密度，在原生坐标上做TM边缘积分。真实方程／真超边只用于独立诊断与最终评分，不提供给拟合器或SPT切分。未通过拟合验收的条件保留失败原因，不靠树恰好吻合验收。

SPT保持固定完整未来、独立均匀干预、全部非空子集、每节点精确二分、单叶终止和0.01 nats Syn容差；不裁剪显著负值，不通过放松精度制造胜出。数值未收敛的完整树可按用户先前要求展示为诊断输出，不能混作通过结果。拟合／积分在共享截止前完成多少报告多少，完整高档和独立验证留有缺口时不自动加算。

探索性目标先取模块F1差≥0.3且SPT≥0.75，作为找候选的工程标准，不是统计显著性界限。候选选定后固定方程、网络、超参数与指标，再用未参与挑选的独立数据／训练种子验证；数值scramble与训练链子集均不能充当独立系统重复。60分钟内若无法完成足够物理重复，只报告点估计和精确缺口，不宣称显著。

保体积映射与新的高阶拓扑先保留为机制上更明确的下一方向，不在本轮同时增加第四个动力学家族和新状态块实现。若Kuramoto/LV首轮无合格候选，报告失败原因，再决定是否转向该方向；不无期限扫参直到出现漂亮分数。
