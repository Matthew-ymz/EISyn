# Runge MLP-TM-EI + PEID 实验细节披露

## 1. 文档范围

本文档只说明 Runge 海平面气压实验中 MLP-TM-EI、二阶 PEID、Hyper-ACE、Hyper-ACS 和 Hyper-AMCE 的实际计算流程。它不覆盖 UniCM ENSO 实验，也不把统计关系解释成已经得到物理验证的大气传播路径。

这里区分三类信息：

- **已确认**：可以由当前实现、运行配置或保存结果直接核对。
- **实现含义**：不是原始论文的原句，但可以由当前算法直接推出。
- **限制**：当前实现没有完成、证据不足，或容易被误读的部分。

最重要的预处理结论是：**实验做了去季节化，也做了线性去趋势。** 去季节化按每个日历日逐格点计算多年气候态，而不是只减去月平均。

## 2. 实验回答什么问题

实验先把全球海平面气压场压缩成 60 个旋转主成分，再学习最近 4 周状态到下一周状态的预测映射。随后在训练期支持范围内对输入做独立最大熵干预，用连续 transport-map 互信息估计器读取：

1. 单个源模态对目标模态的 pairwise EI；
2. 两个源模态联合时超出两个单源 EI 之和的二阶增量；
3. 将 pairwise 路径效应和二阶增量汇总后的 gateway、susceptibility 和 mediator 排名。

因此，该实验测量的是**训练后预测映射在人工干预分布下的信息依赖结构**。它不是天气预报技能评估，不是观测干预试验，也不能单独证明真实大气中的因果传播机制。

## 3. 数据来源

### 3.1 数据产品

| 项目 | 实际口径 |
|---|---|
| 数据机构 | NOAA Physical Sciences Laboratory |
| 数据产品 | NCEP/NCAR Reanalysis 1 |
| 变量 | mean daily sea level pressure，变量名为 `slp` |
| 原始单位 | Pa |
| 网格 | 全球 $2.5^\circ\times2.5^\circ$，73 个纬度点、144 个经度点，共 10,512 个格点 |
| 原始时间分辨率 | 日平均 |
| 当前运行使用时段 | 1948-01-01 至 2011-12-31 |
| 原始日样本数 | 23,376 |
| 下载来源 | `https://downloads.psl.noaa.gov/Datasets/ncep.reanalysis/Dailies/surface/slp.<year>.nc` |

本地数据还包含 2012 年文件，原始 Runge 论文也描述了 1948–2012 年资料，但**当前保存的复现实验配置截至 2011 年**。因此，本报告中的 MLP-TM-EI 和 PEID 数值对应 1948–2011 年，不应写成使用了完整 1948–2012 年。

### 3.2 空间范围

处理使用完整全球网格，没有在 PCA 前裁剪到某个海盆或纬度带。纬向面积差异通过 $\sqrt{\cos\phi}$ 权重处理，其中 $\phi$ 为纬度。使用平方根权重是为了让欧氏内积中的平方权重对应格点面积比例。

## 4. 从日气压场到 60 个周尺度模态

### 4.1 日历日去季节化

先删除所有闰日 2 月 29 日，使每年都使用同一套 365-day 日历。对每个格点和每个 365-day 日历日 $d$，再用完整 1948–2011 年样本计算多年均值 $\mu_d$ 和多年标准差 $\sigma_d$。原始气压 $p_t$ 转换为标准化日异常：

$$
z_t=\frac{p_t-\mu_{d(t)}}{\sigma_{d(t)}}.
$$

这一步同时完成：

- 减去逐日气候态，即去除平均年循环；
- 按逐日气候标准差缩放，使不同季节的异常量级可比。

若某个格点某个日历日的标准差无效或不大于零，分母被替换为 1。计算后仍然缺失的值被填为 0，即按“零标准化异常”处理。

**结论：做了去季节化。** 当前口径与 Wang, Meng & Fan (2023) 一样先移除 2 月 29 日，再按 365-day 日历日对齐多年样本。但气候态和逐日标准差使用完整时段估计，不是仅用监督学习训练段估计。

### 4.2 线性去趋势

在日历日标准化之后，对每个格点沿完整日时间轴拟合线性趋势，并减去拟合值。若把格点 $g$ 的标准化异常写成 $z_{t,g}$，处理为

$$
z^{\mathrm{dt}}_{t,g}=z_{t,g}-(a_g+b_g t).
$$

**结论：做了逐格点线性去趋势。** 当前流程没有使用高阶趋势、分段趋势或外部强迫回归。

### 4.3 月尺度场用于拟合空间模态

去季节化、去趋势后的日场先按自然月求平均。PCA 和 Varimax 的空间载荷使用这些月平均异常场拟合，而不是直接在周平均场上拟合。

对纬度加权后的月场展平为矩阵 $\mathbf{X}\in\mathbb{R}^{T\times10512}$，再次对每个空间列中心化，然后用 full-SVD PCA 保留 60 个分量。之后对 PCA 载荷做正交 Varimax 旋转，并按旋转后方差从高到低排序。

当前 PCA 使用确定性的 full-SVD。虽然运行配置记录了随机种子 42，但该种子不参与这一 PCA 求解。

### 4.4 投影回日尺度并形成周序列

月场只用于拟合空间基底。得到旋转载荷后，将完整的日尺度标准化、去趋势场投影到同一基底，得到 60 个日模态分数。每个模态分数随后在完整时段上再次中心化并按样本标准差标准化。

日模态从 1948-01-01 开始，每连续 7 天做一次算术平均。周标签取该 7 天块的第一天。不能组成完整 7 天块的末尾 3 天被丢弃。最终得到：

- 3,337 个周样本；
- 60 个 Varimax 模态；
- 周标签从 1948-01-01 到 2011-12-24。

这不是按 ISO 周或固定星期几重采样，而是从首日开始的无重叠连续 7 天分块。

### 4.5 缺测值和异常值处理

| 问题 | 实际处理 |
|---|---|
| 原始或中间缺测值 | 日历日标准化后填为 0 |
| PCA 输入中的 NaN、正无穷、负无穷 | 全部替换为 0 |
| 保存周序列中的非有限行 | 读入监督学习前整行删除 |
| 极端但有限的观测异常 | 没有单独 winsorize、截断或稳健缩放 |
| 海陆掩膜 | 未使用；SLP 是全球场 |

当前保存的 3,337 行周序列均为完整数值行。

### 4.6 需要披露的数据泄漏边界

日历日气候态、逐格点趋势、PCA/Varimax 空间基底以及日模态的最终均值和标准差均使用完整 1948–2011 年时段估计，其中包含后续验证段和测试段。监督预测器的输入/输出 scaler 与模型参数只在训练段拟合，但前置空间处理并非严格的训练期拟合。

因此：

- 若目标是复现 Runge 式全时段空间模态，当前处理口径是一致的；
- 若目标是无前视偏差的预测性能评估，当前预处理存在全样本信息进入空间表征的风险；
- 本实验的测试 RMSE 应主要用于确认预测器不是失效模型，不应作为严格的实时预报技能结论。

## 5. 监督样本和时间切分

### 5.1 输入和目标

令 $\mathbf{x}_t\in\mathbb{R}^{60}$ 为第 $t$ 周的模态向量。每个监督样本使用最近 4 周预测下一周：

$$
\mathbf{u}_t=
[\mathbf{x}_{t-3}^{\mathsf T},\mathbf{x}_{t-2}^{\mathsf T},
\mathbf{x}_{t-1}^{\mathsf T},\mathbf{x}_{t}^{\mathsf T}]^{\mathsf T}
\in\mathbb{R}^{240},
\qquad
\mathbf{y}_t=\mathbf{x}_{t+1}\in\mathbb{R}^{60}.
$$

3,337 个周状态形成 3,333 个滞后监督样本。

### 5.2 按时间顺序切分

数据没有随机打乱后再切分，而是按时间顺序使用 70%/15%/15%：

| 分区 | 样本数 | 目标周范围 |
|---|---:|---|
| 训练 | 2,333 | 1948-01-29 至 1992-10-20 |
| 验证 | 500 | 1992-10-27 至 2002-05-23 |
| 测试 | 500 | 2002-05-30 至 2011-12-24 |

输入和目标分别使用训练段均值和标准差做 z-score；验证段和测试段复用训练段 scaler。因此模型训练阶段本身没有用验证或测试目标拟合 scaler。

## 6. 预测器不是单一 MLP

### 6.1 基础残差网络

每个成员都是一个带冻结线性跳连的残差 MLP：

$$
\widehat{\mathbf{y}}
=\mathbf{W}_{\mathrm{ridge}}\mathbf{u}+\mathbf{b}_{\mathrm{ridge}}
+\gamma f_{\theta}(\mathbf{u}).
$$

实际运行参数为：

| 项目 | 值 |
|---|---:|
| 输入维度 | 240 |
| 输出维度 | 60 |
| 隐层数 | 1 |
| 隐层宽度 | 128 |
| 隐层结构 | Linear → LayerNorm → SiLU → Dropout |
| dropout | 0.5 |
| 最大 epoch | 120 |
| batch size | 256 |
| optimizer | AdamW |
| learning rate | $10^{-3}$ |
| weight decay | $10^{-3}$ |
| gradient clip | 1.0 |
| 学习率调度 | 验证 MSE plateau 后乘 0.5，patience 20 |
| early stopping patience | 80 |
| 最小改进 | $10^{-5}$ |
| 随机种子 | 42 |

线性跳连先由标准化训练数据上的 Ridge 解初始化，然后被冻结。非线性 residual head 从零权重和零偏置开始训练。训练后还在验证集上从 $[-0.5,0.5]$ 的 101 个等距值中选择 residual 缩放系数 $\gamma$。

### 6.2 四成员集成和线性融合

实际结果不是单个网络输出。四个成员分别用 Ridge 惩罚系数 10、100、1,000、3,000 初始化冻结跳连，训练后的预测先做等权平均。然后在验证集上用 101 点网格选择该集成与另一个 Ridge($\alpha=1000$) 的权重。

最终预测器为：

$$
\widehat{\mathbf{y}}_{\mathrm{final}}
=0.63\,\widehat{\mathbf{y}}_{\mathrm{MLP\ ensemble}}
+0.37\,\widehat{\mathbf{y}}_{\mathrm{Ridge}(1000)}.
$$

因此“MLP-TM-EI”是简写。更准确地说，它是**Ridge 初始化的残差 MLP 集成与 Ridge 的验证集融合模型，再用 transport-map 估计器做 EI 读出**。

当前保存的主结果复用了四个与配置哈希匹配的模型缓存，没有在 PEID 运行中重新训练。四个成员使用同一随机种子，成员差异主要来自 Ridge 跳连惩罚系数及其后续残差训练，而不是独立随机初始化种子。

### 6.3 一步预测结果

| 模型 | test RMSE | test MAE | test correlation |
|---|---:|---:|---:|
| 最终融合模型 | 0.713185 | 0.568283 | 0.461528 |
| tuned Ridge，$\alpha=1000$ | 0.714727 | 0.569527 | 0.458594 |
| 参考 Ridge，$\alpha=1$ | 0.725256 | 0.578062 | 0.454692 |

保存的显著性摘要给出最终模型相对 tuned Ridge 的 RMSE 改进为 0.001376。对 500 个测试周做 5,000 次、块长 26 周的配对循环块 bootstrap 后，95% 区间为 $[0.000893,0.001825]$，改进不大于 0 的比例为 0.0002。

这个提升在统计上稳定，但绝对量级很小。它只支持“非线性融合预测器可以用于结构读出”，不支持显著提升实际预测技能。另一个复现限制是：当前主实验驱动程序不直接生成这份显著性摘要；摘要值已保存，但从主入口到该摘要的单步生成链没有完整固化。

## 7. 最大熵干预分布

### 7.1 干预样本

对 240 个滞后输入维度分别从训练段计算 5% 和 95% 分位数。每个维度在自己的分位区间内独立均匀采样：

$$
U_k\sim\operatorname{Uniform}(q_{0.05,k},q_{0.95,k}),
\qquad k=1,\ldots,240.
$$

不同维度、不同模态和不同历史周之间全部独立。共生成 4,096 个干预样本，随机种子由主种子 42 确定。所有 pairwise EI 和二阶 EI 使用同一批输入及其模型输出，以减少不同阶次之间的 Monte Carlo 基线差异。

该分布被称为 bounded maximum-entropy intervention，因为在每个给定有限区间内，均匀分布具有最大微分熵。它不是从观测联合分布重采样，因此会主动打破原有跨变量和跨周相关性。

### 7.2 source 的实际定义

虽然预测模型接收完整 4 周历史，当前 EI 的 `source` 只取源模态最近一周的值 $x_{i,t}$。更早 3 周仍参与预测，但被视为随机背景变量，不进入该源的 EI 向量。

因此 pairwise 读数是

$$
EI_{i\to j}=I_{\mathrm{TM}}(U_{i,t};\widehat X_{j,t+1}),
$$

不是 $I(\mathbf{x}_{i,t-3:t};X_{j,t+1})$，也不是控制其余变量后的条件互信息。

## 8. transport-map EI 估计

### 8.1 密度模型

对源样本、目标预测以及它们的联合样本分别拟合三阶多项式三角 transport-map 密度。联合变量按“目标在前、源在后”的顺序排列。每个维度的条件均值由之前维度的三阶多项式回归给出，残差按高斯尺度建模。

互信息以 bit 为单位计算：

$$
\widehat I_{\mathrm{TM}}(X;Y)
=\frac{1}{N}\sum_{r=1}^{N}
\log_2\frac{\widehat p_{XY}(x_r,y_r)}
{\widehat p_X(x_r)\widehat p_Y(y_r)}.
$$

当前估计器没有有限样本 bias correction，保存的 bias correction 为 0。实现虽然接受 jitter 参数，但当前多项式 transport-map 拟合没有实际使用该参数；多项式回归自身使用 $10^{-6}$ Ridge 稳定项。所有负的互信息估计在进入 EI 矩阵前截断为 0。

### 8.2 pairwise EI 图

对 60 个源和 60 个目标计算完整 $60\times60$ EI 矩阵。构造路径图时：

1. 将负值截为 0；
2. 将自环置为 0；
3. 每个源只保留 EI 最大的 5 条正边。

最终直接图有 $60\times5=300$ 条边。图稀疏化没有额外显著性检验，因此这些边是“每源 Top-5”，不是通过统计检验的因果边。

## 9. 二阶 PEID

### 9.1 候选集不是全穷举

二阶计算先按每个源的非自环 outgoing EI 总和选出前 14 个候选源。对每个候选源保留其最强 10 个正 EI 目标。对候选源对 $(i,k)$，目标集合取两个源目标集合的并集，并排除 $i$ 和 $k$ 本身。

最终计算 1,625 个二源—目标组合。因而当前结果是**候选筛选后的二阶 PEID**，不是全部 $\binom{60}{2}$ 个源对对全部目标的穷举。

### 9.2 二源联合 EI 和 Möbius 增量

对源对 $K=\{i,k\}$ 和目标 $j$，联合 EI 使用最近一周的二维源向量：

$$
EI_{\{i,k\}\to j}
=I_{\mathrm{TM}}([U_{i,t},U_{k,t}];\widehat X_{j,t+1}).
$$

二阶 Möbius 增量为

$$
\Delta_{\{i,k\}}(j)
=EI_{\{i,k\}\to j}-EI_{i\to j}-EI_{k\to j}.
$$

$\Delta_2>0$ 表示联合观察两个源得到的 EI 大于两个单源 EI 之和；$\Delta_2<0$ 表示冗余、估计误差或反协调。它不是标准 PID 中保证非负的 synergy atom，因此本文只把正值称为“正二阶协同增量”。

### 9.3 当前显著性筛选

每条二阶候选边建立 20 个 null 样本。具体做法是把 4,096 个模型预测行循环平移，平移量为 26 的倍数，再与未平移的干预输入重新配对并重估 EI 和 $\Delta_2$。由 null 均值和样本标准差计算

$$
z=\frac{\Delta_2-\mu_{\mathrm{null}}}{\sigma_{\mathrm{null}}}.
$$

Hyper 指标保留 $|z|\ge2$ 的二阶项。当前 1,625 个候选中有 307 个满足该阈值，其中 288 个为正增量、19 个为负增量。

同时保存双侧经验 $p$ 值：

$$
p_{\mathrm{emp}}
=\frac{1+\#\{|\Delta_2^{(b)}|\ge|\Delta_2|\}}{20+1}.
$$

由于只有 20 次 null 重复，经验 $p$ 值的最小分辨率是 $1/21\approx0.0476$。而且 Hyper 指标实际按 $|z|\ge2$ 筛选，并没有再要求经验 $p<0.05$。

### 9.4 对 null 的关键限制

这一步在代码注释中称为 block-bootstrap null，但平移的是**独立干预样本的模型预测行**，不是按时间排列的原始周观测或测试残差。独立干预样本的行顺序没有周时间含义，因此块长 26 不能在这里严格解释为保留“半年尺度时间自相关”。

更准确的说法是：当前 null 是一种保持边际样本、破坏源—目标行配对的循环平移置换。它可以提供数值筛选基线，但不能替代基于原始时间序列的块 bootstrap。当前二阶显著性比例偏高，也提示后续需要更严格的 null、更多重复以及多重检验控制。

## 10. 路径效应和节点指标

### 10.1 pairwise 路径矩阵

令 $\mathbf{E}$ 为稀疏化后的非负 EI 矩阵。对角线为 0。若谱半径过大，按目标谱半径 $\alpha=0.8$ 缩放；当前运行的实际缩放因子为 1，因此没有发生数值缩放。记处理后的矩阵为 $\mathbf{A}$。

总路径效应累加到 60 阶：

$$
\mathbf{T}=\sum_{\ell=1}^{60}\mathbf{A}^{\ell}.
$$

三个 pairwise 指标为

$$
\mathrm{ACE}(i)=\frac{1}{59}\sum_{j\ne i}T_{ij},
\qquad
\mathrm{ACS}(i)=\frac{1}{59}\sum_{j\ne i}T_{ji},
$$

$$
\mathrm{AMCE}(m)=\frac{1}{59\times58}
\sum_{\substack{s\ne m,\ j\ne m\\s\ne j}}
A_{sm}T_{mj}.
$$

ACE 表示累计 outgoing path effect，ACS 表示累计 incoming susceptibility，AMCE 表示节点位于“源先到该节点、再从该节点到目标”的路径中的强度。

### 10.2 Hyper-ACE

一阶部分直接累计完整 EI 矩阵中的绝对一阶增量；二阶部分只累计 $|z|\ge2$ 的候选边，并把每条二源增量平均分给两个源成员：

$$
\mathrm{Hyper\text{-}ACE}(i)
=\frac{1}{59}\left[
\sum_j|EI_{i\to j}|
+\sum_{\substack{(K,j):i\in K\\|K|=2,\ |z|\ge2}}
\frac{|\Delta_K(j)|}{2}
\right].
$$

实现的一阶项包含 EI 矩阵对角元素，而 pairwise 路径 ACE 在构图前删除自环。这是两种排名口径之间的一个差异。

### 10.3 Hyper-ACS

Hyper-ACS 由绘图阶段按目标汇总：

$$
\mathrm{Hyper\text{-}ACS}(j)
=\frac{1}{59}\left[
\sum_i|EI_{i\to j}|
+\sum_{\substack{(K,j):|K|=2,\ |z|\ge2}}
|\Delta_K(j)|
\right].
$$

二阶目标贡献不在两个源之间拆分，因为该节点本身就是超边目标。

### 10.4 Hyper-AMCE

当前 Hyper-AMCE 将 pairwise 路径 AMCE 与“节点作为显著二源组合成员”的贡献相加：

$$
\mathrm{Hyper\text{-}AMCE}(m)
=\mathrm{AMCE}(m)
+\frac{1}{59}
\sum_{\substack{(K,j):m\in K\\|K|=2,\ |z|\ge2}}
\frac{|\Delta_K(j)|}{2}.
$$

因此 Hyper-AMCE 不等于严格意义上的高阶中介效应。其二阶部分衡量节点作为协同源成员的强度，而不是证明信息真实经过该节点传播。

## 11. 模态编号和地图位置

保存的数组使用一基名称，例如第一个数组分量写作 component 01；报告地图使用零基 `No.0`、`No.1` 等标签。大部分分量按 `component 01 → No.0` 对应。

为了与 Runge 原文图中的已讨论区域对齐，当前可视化还人工交换了三对标签：`No.7/No.18`、`No.8/No.26` 和 `No.21/No.48`。这些交换依据发布图中的空间位置进行视觉校准，不是由独立匹配目标自动估计。因而对这些节点的跨论文编号比较应保留这一人工校准说明。

节点坐标也不是观测站位置。每个点来自对应 Varimax loading 的高载荷中心，表示一个空间模态的代表位置。

## 12. 当前结果可支持和不能支持的结论

### 12.1 可以支持

- 在当前全时段空间预处理和独立均匀干预口径下，融合预测器存在可重复读取的 pairwise 信息结构。
- 二源联合 EI 会改变部分源侧 gateway 排名，说明 pairwise 排名不能完整代表筛选后的二阶增量。
- No.0 在 pairwise 与 Hyper 排名中都较稳定；No.18、No.13 等节点在二阶成员汇总中较突出。

### 12.2 不能直接支持

- 不能把超边画成真实风场、能量流或空气团轨迹。
- 不能把 $\Delta_2>0$ 自动等同于标准 PID 中唯一且非负的 synergy atom。
- 不能把 $|z|\ge2$ 当作经过充分多重检验校正的显著性结论。
- 不能把 0.0014 左右的 RMSE 改进表述为明显预测性能突破。
- 不能把使用全时段气候态和 PCA 的测试结果当作严格无泄漏的实时预报评估。
- 不能把候选筛选后的 1,625 条二阶组合说成全 60 维系统的穷举 PEID。
- 不能把确定性预测器输出下的 EI 当作包含观测误差、模型误差和内部气候噪声的完整信息传递量。

## 14. 可直接用于论文附录的方法摘要

我们使用 NOAA NCEP/NCAR Reanalysis 1 的全球日平均海平面气压资料。当前实验覆盖 1948–2011 年，原始网格分辨率为 $2.5^\circ$。预处理先删除所有 2 月 29 日，使每年具有相同的 365-day 日历；随后对每个格点按 365-day 日历日计算多年均值和标准差，形成标准化日异常，并进一步移除逐格点线性趋势。空间场乘以 $\sqrt{\cos\phi}$ 纬度权重后，先聚合为月平均异常场，再拟合 60 维 PCA 并进行正交 Varimax 旋转。旋转载荷被投影回日尺度异常场，所得模态分数在完整时段上标准化，再按连续 7 天无重叠平均形成周状态。

预测样本使用最近 4 周的 60 维状态预测下一周状态，并按时间顺序切分为 70% 训练、15% 验证和 15% 测试。预测器由四个带冻结 Ridge 跳连的残差 MLP 等权集成，再与 Ridge 模型按验证集 RMSE 进行线性融合。最终融合权重为 0.63 和 0.37。测试集 RMSE、MAE 和相关系数分别为 0.713185、0.568283 和 0.461528。

信息读出在训练输入逐维 5%–95% 分位区间内生成 4,096 个独立均匀干预样本。预测器接收完整 4 周干预历史，但每个 EI source 只使用最近一周的源模态。源与目标预测之间的互信息由三阶多项式三角 transport-map 密度估计器计算，负估计截为 0。pairwise EI 图对每个源保留最强 5 条非自环正边，并用最长 60 步的矩阵幂和计算 ACE、ACS 和 AMCE。

二阶分析先按 outgoing pairwise EI 选择 14 个候选源，再从每个源的前 10 个目标构造 1,625 个源对—目标组合。二阶增量定义为联合 EI 减去两个单源 EI。当前 Hyper 指标使用 20 次预测行循环平移得到的 null z-score，并保留 $|z|\ge2$ 的二阶项。由于该 null 作用于独立干预样本而非原始周时间序列，且没有多重检验校正，二阶超边应视为后续物理检验的候选关系，而非已经确认的气候因果机制。
