# 综合实验设计方案：城市内部 NOx–VOC–气象协同机制与 PEID 因果超图分析

## 0. 研究总问题

本研究选择一个城市，优先推荐北京，也可以替换为上海，利用该城市内部多个空气质量监测站点的时间序列数据，比较市中心与郊区在污染形成机制上的差异。

核心问题包括：

1. 当 O₃ 作为因变量时，NOx、VOC、温度、相对湿度之间是否存在协同效应？
2. 市中心与郊区是否处于不同的 O₃ 控制区，例如 VOC-limited、NOx-limited 或 transition？
3. 当 PM2.5 作为因变量时，温度与 RH 的协同效应是否仍然存在？这种效应是否会被 NO₂/NOx 调节？
4. 随机森林学习到的预测机制中，哪些变量形成单独有效因果边，哪些变量形成不可约的协同因果超边？
5. 能否用 PEID 因果图替代 SHAP，对随机森林模型进行机制解释？

---

## 1. 城市选择

### 1.1 推荐城市

首选：北京

理由：

- 北京具有明显的中心城区、近郊和远郊结构。
- 市中心交通、商业、旅游活动强，NOx 排放较高。
- 郊区和下风向区域更容易表现出气团输送、光化学老化和 O₃ 累积。
- 中心城区与郊区可能处于不同 O₃ 控制区，适合检验 NOx–VOC 响应曲面的空间异质性。

备选：上海

理由：

- 上海具有中心城区、郊区和沿海背景站差异。
- O₃ 污染与海陆风、区域输送、工业和交通排放密切相关。
- 适合研究沿海城市中 O₃ 和 PM2.5 的协同治理问题。

## 2. 数据结构

### 2.1 基础数据表

建议整理成长表格式：

| datetime | city | station_id | station_name | lon | lat | station_type | PM2.5 | O3 | MDA8_O3 | NO2 | NOx | VOC | HCHO | Temp | RH | WS | WD | BLH | SSR | TP |
|---|---|---|---|---:|---:|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|

其中：

- PM2.5：细颗粒物浓度。
- O3：小时臭氧浓度。
- MDA8_O3：日最大 8 小时滑动平均臭氧，用于 O₃ 分析。
- NO2 或 NOx：NOx 排放/浓度代理变量。
- VOC：挥发性有机物；如果没有地面 VOC，可用 HCHO 或卫星 HCHO 作为 VOC 代理。
- Temp：温度。
- RH：相对湿度。
- WS、WD：风速、风向。
- BLH：边界层高度。
- SSR：太阳辐射。
- TP：降水。

### 2.2 最低数据要求

如果数据较少，最低配置为：

| 变量 | 是否必要 | 用途 |
|---|---|---|
| O3 / MDA8_O3 | 必要 | O₃ 响应面因变量 |
| PM2.5 | 必要 | PM2.5 协同机制因变量 |
| NO2 或 NOx | 必要 | NOx 代理 |
| Temp | 必要 | 气象协同变量 |
| RH | 必要 | 气象协同变量 |
| station_id | 必要 | 站点分组与空间异质性 |
| lon / lat | 推荐 | 判断中心/郊区与空间距离 |
| VOC / HCHO | 强烈推荐 | 判断 VOC/NOx 控制区 |
| WS / WD / BLH / SSR | 推荐 | 控制输送、扩散、光化学条件 |

如果没有 VOC 或 HCHO，则不能严格画 VOC/NOx 响应曲面，只能做：

O3 = F(NO2, Temp, RH, ...)

这时应称为“NOx–气象经验响应面”，而不是完整 VOC/NOx 响应面。

## 3. 站点分组：市中心 vs 郊区

### 3.1 方法一：距离法

设城市中心点为：

- 北京：天安门或城市行政中心。
- 上海：人民广场或城市几何中心。

计算每个站点到城市中心的距离：

d_s = distance(station_s, city_center)

可定义：

- d_s <= 10 km：中心城区站点。
- 10 km < d_s <= 30 km：近郊站点。
- d_s > 30 km：远郊/背景站点。

### 3.2 方法二：NO₂ 特征法

按站点 NO₂ 年均值或夏季白天 NO₂ 均值划分：

- 高 NO₂ 站点：交通/城市核心型。
- 中 NO₂ 站点：城市混合型。
- 低 NO₂ 站点：郊区/背景型。

### 3.3 推荐分组方法

主分析采用：

station_type = distance_group + NO2_level_group

例如：

- center_high_NO2：中心城区高 NO₂ 站点。
- suburban_mid_NO2：郊区中等 NO₂ 站点。
- background_low_NO2：远郊低 NO₂ 站点。

这样比单纯按行政区分组更稳健。

## 4. 研究假设

## H1：O₃ 存在 NOx × VOC 协同效应

O₃ 不是由 NOx 或 VOC 单独决定，而是由二者比例和共同状态决定。

模型形式：

O3_{t+Δ} = F(NOx_t, VOC_t, Temp_t, RH_t, ...)

或在缺少 VOC 时：

O3_{t+Δ} = F(NO2_t, HCHO_t, Temp_t, RH_t, ...)

重点检验：

SynEID({NOx, VOC} -> O3)

或：

SynEID({NO2, HCHO} -> O3)

预期：

- 市中心可能更偏 VOC-limited 或 NOx-saturated。
- 郊区/下风向可能更偏 NOx-limited 或 transition。
- 中心和郊区的 NOx/VOC 响应曲面形态不同。

---

## H2：O₃ 存在 NOx × VOC × Temp 的三变量协同

温度不仅直接影响 O₃，也会调节 NOx–VOC 光化学反应效率。

模型形式：

O3_{t+Δ} = F(NOx_t, VOC_t, Temp_t, RH_t, SSR_t, ...)

重点检验：

SynEID({NOx, VOC, Temp} -> O3)

预期：

- 高温条件下，NOx/VOC 对 O₃ 的非线性响应更强。
- 在中心城区，高温可能放大 VOC-limited 特征。
- 在郊区，高温可能增强 NOx-limited 或 transition 区域的 O₃ 生成。

---

## H3：O₃ 中也存在 Temp × RH 协同，但不是主机制

模型形式：

O3_{t+Δ} = F(Temp_t, RH_t, NOx_t, VOC_t, ...)

重点检验：

SynEID({Temp, RH} -> O3)

解释：

- 对 O₃ 来说，Temp × RH 是气象调节协同。
- 它不像 PM2.5 中的 Temp × RH 那样直接对应吸湿增长和水相反应。
- Temp 和 RH 更像调节 NOx–VOC 反应面的气象开关。

---

## H4：PM2.5 存在 Temp × RH 协同效应

模型形式：

PM2.5_{t+Δ} = F(Temp_t, RH_t, NO2_t, O3_t, ...)

重点检验：

SynEID({Temp, RH} -> PM2.5)

预期：

- 低温 + 高 RH 条件下，PM2.5 更容易升高。
- 这可能反映硝酸盐分配、硫酸盐水相生成、吸湿增长和静稳积累。
- 但如果缺少化学组分，不能将结果唯一归因于硝酸盐或硫酸盐机制。

---

## H5：PM2.5 中存在 NO₂ × Temp × RH 协同

模型形式：

PM2.5_{t+Δ} = F(NO2_t, Temp_t, RH_t, O3_t, ...)

重点检验：

SynEID({NO2, Temp, RH} -> PM2.5)

预期：

- 在低温高湿条件下，NO₂ 对 PM2.5 的作用可能增强。
- 中心城区由于 NOx 较高，这种协同可能更强。
- 郊区可能更多体现输送和湿度条件，而非本地 NOx 驱动。

---

## 5. 机器学习模型设计

## 5.1 主模型：随机森林

主模型使用 Random Forest Regressor。

理由：

- 适合表格型环境数据。
- 可以捕捉非线性和高阶交互。
- 对变量尺度不敏感。
- 与已有空气质量 deweathering / meteorological normalization 研究路线一致。
- 便于后续构造响应曲面和 PEID 干预采样。

初始参数建议：

```python
RandomForestRegressor(
    n_estimators=500,
    max_features="sqrt",
    min_samples_leaf=10,
    max_depth=None,
    bootstrap=True,
    n_jobs=-1,
    random_state=42
)
