## 原图约等号的来源

## 本轮数值改进与准入

改进重要性采样的提议分布：以在原始相位盒内逐坐标截断的 Gaussian 三角传输，替代会把许多采样点放在盒外的未截断提议。每个新提议都显式计算归一化密度；保留 80% 局部、15% 宽尺度、5% 均匀防御混合，正确使用密度比。改变的是积分效率，原学得 Gaussian 条件 TM、因子化干预和目标不变。

低档四次积分后，边界改进仍留下重权重点。只针对共同分母的提议权重做数值诊断（未以恢复分数作选择）：保留全部试过的局部尺度和混合权重，选用 65% 原局部尺度、30% 两倍标准差尺度、5% 均匀分布。两次诊断中较差的最小 ESS 约为 9.61，高于原提议约 4.12；后续用更大 P 验证全部子集。低档原结果保留作同一积分定义的粗档比较，后续档显式记录新提议；这一变更不修改物理参数、EI 定义或准入阈值。

CPU 双精度向量化加速只复用同一组模型权重；对独立探针检查与原 NumPy 实现的一致性。未采用单精度近似。

后续预算内增加一个显卡加速对照：仅 MLP 前向采用 float32，提议中心/Jacobian、外层样本、协方差和所有密度比仍用 CPU float64。先以完全相同 N=2048、P=512、scramble880 的完整 63 项 EI 对照 CPU float64，最大 EI 差异为 1.033e-7 nats；独立探针的最大 log-density 差异为 2.970e-5 nats，远低于 0.01 nats 门槛。仅在该完整对照通过后允许用于后续积分；审计见 `mps_ei_equivalence.json`。因此后续不是数学精确的浮点等价，剩余浮点误差已单独量化，不与积分收敛混称。

- 新提议需通过一维截断正态解析对照、相关二维分布独立积分归一化、采样矩和完整均匀卷积通道的解析 EI 对照。
- 预定积分阶梯为 (外层 N, 内层 P)：(512,256)、(2048,512)、(4096,512)、(8192,1024)。每档四个预定独立 scramble：880、1880、2880、3880。只因精度未满足而升档，不因 F1 升档或挑档。四个积分随机化不构成四个独立物理数据种子。
- 保留原准入：EI 最大跨档变化<0.01 nats、EI 最大 scramble SEM<0.01 nats、最差 ESS≥10、最大归一化权重≤0.25、独立 scramble 模块树一致、非负审计通过；另要求节点百分比的最大跨档变化及 SEM 均≤1 个百分点。
- 百分比精度在同一组平均树切分上计算：对每个 scramble 和上一档 EI 重新评价当前平均树的局部二分残差。不能把某次积分换成另一个等价的内部配对后“缺席的节点”当成零，否则会把无唯一真值的配对变换误报为百分比误差。模块树稳定性仍独立检查。
- Syn 原生容差为 0.01 nats，记录容差内负值数量和显著违规数。显著违规使该档构树显式失败，不能剪裁或投影。预算到期只保留已完成结果，未通过的门槛不改成通过。
- 通过数值检查后才可去掉提示未收敛的约等号；最终数字仍为有限精度的学得通道估计，不能称为真实 SDE 的精确因果强度。未通过则保留约等号并报告具体残留问题。

## 输出噪声控制变量

四次粗档与前两次中档结果显示，权重改善后仍有明显的外层噪声波动。基于解析高斯噪声的零均值恒等式，引入固定系数为 1 的控制变量；选择依据是积分方差，未按 F1 或节点百分比的大小选择。原始逐样本 EI 和原始精度结果均独立保留。

设完整条件 TM 为 $\boldsymbol{y}=\boldsymbol{f}(\boldsymbol{x})+\boldsymbol{L}\boldsymbol{z}$，其中 $\boldsymbol{z}\sim\mathcal{N}(\boldsymbol{0},\boldsymbol{I})$ 且与均匀干预 $\boldsymbol{x}$ 独立。对每个源集合 A，以其缺失源 C 的白化 Jacobian $\boldsymbol{B}_C(\boldsymbol{x})=\boldsymbol{L}^{-1}\boldsymbol{J}_C(\boldsymbol{x})$ 的列空间构造正交投影 $\boldsymbol{P}_A=\boldsymbol{I}-\boldsymbol{Q}_C\boldsymbol{Q}_C^{\mathsf T}$。逐样本 EI 加上

$$g_A(\boldsymbol{x},\boldsymbol{z})=\tfrac12\left(\boldsymbol{z}^{\mathsf T}\boldsymbol{P}_A(\boldsymbol{x})\boldsymbol{z}-\operatorname{tr}\boldsymbol{P}_A(\boldsymbol{x})\right),\qquad \mathbb{E}[g_A\mid\boldsymbol{x}]=0.$$

因此 EI 的总体定义不变，也不依赖于“局部线性通道精确”假设；Jacobian 只用于构造均值为零的方差控制。非线性/边界效应仍由原全通道积分处理。先用独立协方差精确噪声节点检验控制均值，再对原 EI 表和受控 EI 表分别重做非负与精度审计。所有门槛保持原值，不能把原始表未通过改写成原始表已通过。

复现分析入口为 `scripts/summarize_spt_weak_coupling.py`。该脚本只复用完成的四次积分缓存；未完成的一档不发布。它生成的 `spt_projection.json` 和原始 `spt_raw.json` 并列保存，前者需通过相同 EI 精度门槛及额外百分比门槛后才可标记数值已解决。有限内层积分的偏差仍必须通过跨档比较检验，零均值控制不消除这项偏差。

高精度前两次重复中，噪声控制降低了节点比例波动，但部分绝对 EI 仍受初态相位波动影响。因此在本轮同一绝对预算内增加一个独立数值校准积分（N=512、P=256、scramble9721），不用其树或恢复分数。用前256点拟合、后256点验证 Fourier 控制变量：字典为所有节点的一至三阶谐波，或同一通用全超边 Fourier 字典；ridge 系数为固定候选 1/10/100/1000。仅按全部63项EI的留出 MSE 选取，再在独立校准样本上拟合固定系数。之后冻结，不以四次准入积分的 F1 或节点值调节。

每个非零整数频率的 sin/cos 在原因子化均匀相位盒上期望精确为零。因而条件于独立校准数据，减去任意固定线性组合的 Fourier 项也不改变 EI 的总体期望。此控制可减少相位依赖造成的外层方差，不能修复条件模型错误或有限内层积分偏差。控制系数、所有验证候选和未控制结果均保存；若校准留出 MSE 未优于常数预测，则不采用 Fourier 控制。校准积分与四次精度积分、物理数据种子明确区分。

另做固定外层点的配对内层加密检查：取四次 N=2048、P=512 缓存各自前512个外层点，与相同 x/z 下的新 P=1024 积分比较。该检查只改变 P，不把外层加密和内层变化混在一起。固定共同树，门槛仍为最大 EI 变化及差值 SEM<0.01 nats、最大节点比例变化≤1个百分点；全部结果保存于 `inner_precision_check.json`，不按 F1 筛选。

## 本轮最终结果

在批准预算内正常退出，累计 3,417 秒（56.95 分钟）。最终档为 N=4096、P=512、四次独立 scramble。受控估计的 EI 最大 SEM 为 0.004490 nats、最大跨档变化 0.002947 nats；最差 ESS=11.386、最大归一化权重=0.246494。节点百分比最大 SEM 为 0.26735 个百分点、最大跨档变化为 0.26435 个百分点。固定外层、P=512→1024 的独立配对检查中，EI 最大变化 0.000348 nats，比例最大变化 0.09454 个百分点。所有声明的数值门槛通过，因此图上去掉用于标记未收敛的约等号。

四次受控估计树分别都恢复 123、1234、56；模块 F1 均为 1。最终平均树节点份额为：根 123456 为4.1%、1234 为41.4%、123 为30.8%、12 为14.9%、56 为8.7%。这些是层级分组残差，不是纯阶 PID 原子。

主比较的最强基线仍为 MIC 的0.667；Pairwise MI 与距离相关均为0.571，绝对相关0.333，Ward为0。基线继续取两视图中各自较高得分。结论仅限这一共享物理数据种子；四次积分随机化不等于四次物理数据确认。

最终受控 EI 全部301个二分的最小 Syn 为0.001069 nats；0.01 nats容差内负值计数0、显著违规0，没有剪裁。原始估计仍另存：其节点百分比跨档变化为1.819个百分点，没有通过本轮新增的1个百分点门槛；不能声称原始估计也达到同样精度。15项相关测试通过。实验监看已在完成后删除。
